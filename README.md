# simple-webshop-example
A example of a simple webshop, that i will use as template, and update as i improve

## software used:
- php
- mysql
- docker

## prerequisites to run it:
- docker
if you don't have docker, you can find information here:
![docker](https://www.docker.com/get-started/)

## clone or download the repo

## commands:
make sure you run the commands in the project folder
- build:
    `docker compose build`
- start:
    `docker compose up -d`
- stop:
    `docker compose down -v`
